# 📚 Nossa Estante

## 🚀 Como Rodar o Projeto

### 1. Backend (Spring Boot)
Entre na pasta `backend` e execute o comando correspondente ao seu sistema operacional:

```bash
cd backend
```

* **No Windows:**
  ```powershell
  .\mvnw.cmd spring-boot:run
  ```
* **No Linux/macOS:**
  ```bash
  ./mvnw spring-boot:run
  ```

> 💡 O banco de dados SQLite é criado e configurado automaticamente.
>
> 🌐 **Swagger API:** http://localhost:8080/swagger-ui/index.html

---

### 2. Frontend (React / Vite)
No terminal na raiz do projeto (fora da pasta `backend`), execute os comandos:

```bash
npm install
npm run dev
```

> 🌐 **Frontend:** http://localhost:5173
